# HOUP — houp.mx

Sitio web institucional de HOUP (Promotora de Desarrollo Humano HOUP, S.C.) — organización de desarrollo humano con sede en Monterrey, México.

## Arquitectura

Sitio 100% estático: HTML + CSS + JavaScript. Sin build steps. Hosting: GitHub Pages.

## Páginas

- `index.html` — Home
- `educacion.html` — HOUP Educación
- `empresas.html` — HOUP Empresas (metodología 4 C's)
- `fundacion.html` — HOUP Fundación
- `nosotros.html` — Historia, metodología, equipo
- `contacto.html` — Formulario y contactos por rama
- `aviso-de-privacidad.html` — LFPDPPP
- `404.html` — Página de error

## Assets

- `css/styles.css` — sistema visual completo + animaciones
- `js/main.js` — scroll animations, menú móvil, counter
- `img/favicon/` — set completo
- `img/fotos/` — fotografía institucional
- `img/logos/` — variantes de logo
- `img/og/` — Open Graph image
